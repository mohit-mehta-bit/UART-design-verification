# UART-design-verification


## Overview

Designed and verified a UART communication interface using
SystemVerilog RTL.

The project implements UART transmitter and receiver logic and
verifies serial data transmission and reception using a
SystemVerilog testbench.

## RTL Design

- UART Transmitter
- UART Receiver
- Serial data transmission and reception
- Start bit and stop bit handling
- 8-bit data transmission
- Configurable baud rate

## Verification

- Verified UART transmit operation
- Verified UART receive operation
- Checked correct start bit and stop bit detection
- Verified serial data transmission and reception
- Analyzed simulation waveforms

## Tools

- Verilog
- SystemVerilog
- EDA Playground
